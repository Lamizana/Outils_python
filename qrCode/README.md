# Qr Code

## Objectif

Génération d'un Qr Code à partir d'une adresse mail en python.

Voici les étapes que nous allons suivre :

- Comprendre ce qu'est un QR Code et le format mailto:
- Valider une adresse email avec une expression régulière (regex)
- Générer un QR Code avec la bibliothèque qrcode
- Assembler le tout dans un script avec argparse
- Bonnes pratiques et améliorations possibles
